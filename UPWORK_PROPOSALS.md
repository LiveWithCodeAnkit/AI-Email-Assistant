## Usage Guide

### Step 1: Setup API Key
1. Navigate to the Upwork Proposals page (`/upwork`)
2. Enter your OpenAI API key in the API Key Manager
3. The key is securely stored locally with encryption

### Step 2: Choose Your Approach
1. **Use Templates**: Browse 10+ professional templates with proven win rates
2. **Load Saved Profile**: Quick-load previously saved freelancer profiles
3. **Start Fresh**: Create a new proposal from scratch

### Step 3: Generate Proposal
1. **🤖 AI Model Selection**: Choose your preferred AI model (always visible with performance guidance)
2. **Select Profile**: Choose your freelancer profile type (auto-filled if using template)
3. **About You**: Describe your background, skills, and experience OR upload resume for auto-extraction
4. **📄 Resume Upload** (NEW): Upload PDF/DOC/TXT files to automatically extract and analyze your background
5. **Project Details** (Enhanced):
   - Client/Company name for personalization
   - Project budget range for strategy optimization
   - Timeline requirements for urgency handling
   - Special requirements (NDA, timezone, etc.)
6. **Advanced Fields**:
   - Experience years with intelligent matching
   - **Smart Keywords**: Industry-specific suggestions with auto-completion
   - Portfolio links with validation
   - Proposal tone and length with strategy alignment
7. **Job Requirements**: Paste complete job posting in scrollable, resizable text area
8. **Real-time Insights**: View automatic job analysis (urgency, budget, complexity, tech stack, client type)
9. **Generate**: Create optimized proposal with real Upwork pattern analysis

### Step 4: Optimize, Analyze & Translate
1. **📊 Enhanced Quality Analysis**: Get detailed scoring across 7 quality factors with performance ratings
2. **✨ Optimization**: Choose from 5 optimization strategies (General, Budget, Timeline, Quality, Competition)
3. **🌐 Multi-Language Translation**: Translate to Hindi (हिंदी), Gujarati (ગુજરાતી), or English for international clients
4. **📋 Multiple Versions**: Compare original, optimized, and translated proposals in tabbed interface
5. **📜 Scrollable Content**: All proposals display in scrollable areas for easy reading of large content
6. **💾 Export Options**: Save any version in multiple formats with proper naming

### Step 5: Analyze Client Reviews
1. Switch to the "Analyze Client Reviews" tab
2. Paste comprehensive client reviews and feedback
3. Get detailed client behavior analysis including:
   - Communication style and preferences
   - Decision-making factors and priorities
   - Pain points and success indicators
   - Proposal strategy recommendations

### Step 6: Track Success
